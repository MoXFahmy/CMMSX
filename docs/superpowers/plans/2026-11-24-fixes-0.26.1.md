# 0.26.1 Fix Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 21 deferred minor issues the user picked from 0.24.0–0.26.0, each with a test that fails first.

**Architecture:** Small, local changes in the existing endpoints, services and pages; no new tables or permissions. Each task groups one release's fixes and ends green.

**Tech Stack:** ASP.NET Core 10 minimal APIs, EF Core 10 / SQL Server; React 19 + Mantine 8; xUnit `SkippableFact` + `ApiFixture`; Vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-fixes-0.26.1-design.md`

## Global Constraints

- Messages (exact): "A serial-tracked part can't also be a shelf-life item." · "Receive a repair line whole." · "Showing the first 500 units." (web) · "API keys can't do this." (existing).
- Units list cap stays 500 (`SerialUnitEndpoints`); the answer carries `capped: true` when more matched.
- `ImportJob.Error` is at most 1,000 characters.
- No new permissions, no migration.
- Every new message in English and Arabic.

## Review Focus

1. **A site-limited technician fits a unit:** the Fit dialog's list of units shows only units in stores they can see. Test `Fit_candidates_follow_sites` (Task 1).
2. **An Arabic organization searches the log in Arabic** for a value it changed: the entry is found. Test `Search_finds_arabic_values` (Task 2).
3. **A crash between an import's save and its "done" mark** can't happen: the mark is written in the import's own transaction. Test `Done_is_saved_with_the_import` (Task 3).
4. **A site-limited admin's storage list** hides other sites' files but the totals stay. Test `Storage_list_follows_sites` (Task 2).
5. **Anonymising someone with e-mails in the log**: their old address and name are gone from the e-mail log. Test `Anonymise_reaches_the_email_log` (Task 2).
