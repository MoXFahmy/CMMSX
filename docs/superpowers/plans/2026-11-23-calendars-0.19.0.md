# Calendars, availability and the daily timesheet (0.19.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plan by the day with real availability (time away and extra time), contractor visits on the planning board, and a
daily timesheet on the web and the phone.

**Architecture:** One pure function decides a person's available hours on a day; one server query
(`AvailabilityQueries.DaysAsync`) feeds the board, its warnings, the timesheet and the phone bundle. Planned hours per
person-day move from the browser to the server. Contractor lines gain a visit date and the board a "by contractor" view. The
timesheet is a new view over the existing labour records.

**Tech Stack:** ASP.NET Core 10 minimal APIs, EF Core 10 (SQL Server), React 19 + Mantine 8 + TanStack Query + i18next, the
offline technician app in `web/src/tech`, xUnit (`SkippableFact`, `ApiFixture`), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-23-calendars-0.19.0-design.md`

## Global Constraints

- Plan by the day: work orders stay dated (`PlannedStart` is a `DateOnly`); no clock times, no hourly view.
- Availability warns, never refuses.
- One function computes available hours: pattern hours − time away (an entry without hours = the whole pattern day; never
  below 0) + extra time.
- No new permissions: types with *Manage settings*; entries with *Manage people* or *Edit work orders*; board with *View work
  orders*; moves with *Edit work orders*; "Assign to me" and visit reports with *Execute work orders*; others' timesheets and
  the week view with *Edit work orders* or *Log hours for others*.
- The timesheet changes only `WorkOrderLabor` through the existing labour endpoints and rules.
- Every new text in English and Arabic (server `Localization/ar.json`; web `locales/en.json` + `ar.json`, Arabic plurals
  `_zero/_one/_two/_few/_many/_other`).
- Gate releases with CI's exact server commands (`dotnet build server/FourC.Cmms.slnx -c Release`, then
  `dotnet test … -c Release --no-build`), not only the test project's build.

## Review Focus

1. **A team entry after a member joins or leaves** counts for whoever is a member when read. Test: `Team_entry_follows_current_members` (Task 3).
2. **The board, its warnings and the timesheet disagree on a day's hours.** Test: `Board_and_timesheet_agree_on_available_hours` (Task 5).
3. **The timesheet double-counts or loses labour cost.** Test: `Day_total_matches_work_order_labour` (Task 5).
4. **"Assign to me" pressed by two people at once.** Test: `Assign_to_me_takes_unassigned_work_once` (Task 3).
5. **A finished job's hours vanish from the phone's day.** Test: `Bundle_carries_my_last_30_days_of_hours_on_every_work_order` (Task 6).
