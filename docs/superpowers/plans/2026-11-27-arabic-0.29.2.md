## Rulings made while planning (from the code survey)

- **P1 (charts):** `useChartAxes` merges, never replaces, a chart's own `yAxisProps`. ReportsPage's custom `AxisTick` anchors at
  `start` in Arabic.
- **P2 (datatable):** the 47 `textAlign: 'right'` stay in code. `web/src/styles.css` maps `.mantine-datatable-text-align-right` to
  `text-align: end` and `-left` to `start`, outside any CSS layer. The web guard checks that rule exists.
- **P3 (server guard):** message contexts per code map §4 (`DomainException(`, `Validator` `.Add/.When/.Required/.MaxLength`
  labels exact, `Results.Problem(title:`, `Translator.T(`). Interpolations become `{N}` and are checked with sample values. The
  allow-list file `server/FourC.Cmms.Tests/arabic-coverage-allowlist.txt` uses `file | 40-char fingerprint | reason`, like
  `guard-filter-lift-allowlist.txt`. Log lines, AI prompts, SQL and sample data are never scanned or are allow-listed.
- **P4 (stored lines):** stored text keeps its exact English form. Translation happens once, server side, where the line leaves
  for a screen or export. Old rows must match the same templates.
- **P5 (exports):** the web adds `ui-culture=<language>` to every export URL (the server's query-string culture provider outranks
  the browser's `Accept-Language`).
- **P6 (AI skip list):** `skip` holds at most 2,000 ids; more → 400 "Too many texts to leave out." Unknown or foreign ids are
  ignored. The skip list is a filter only: it never saves.
- **P7 (steps' order):** if a steps-only edit doesn't stamp its template's `UpdatedAt` today, Task 5 makes the template's own save
  endpoint stamp it. No migration.
- **P8 (review sheet):** not a task. After Task 6 the controller builds the review sheet (both ar.json files, with first-pass
  flags) in the Drive folder. Corrections ship in a later release.
